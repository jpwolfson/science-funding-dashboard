How to read this obligation ledger
Obligations, not appropriations or outlays. The dollar series measures signed obligations charged to this federal account. Congress's appropriation is the starting authority; outlays occur later.
Reported in submission periods. Values are attributed to agency reporting periods, not reconstructed award-action dates. The first P02 bucket covers the first reporting window, and historical quarterly submissions appear only at quarter ends.
Negative activity stays negative. Downward adjustments, terminations, clawbacks, and negative reconciliation residuals reduce period and cumulative totals instead of disappearing from the history. A negative entry alone does not establish cancellation; that classification requires separate source evidence.
File C is award-financial enrichment. Across the full displayed history, File C / net is 18.6%. Award and recipient tables include only File C rows linked to public awards; the residual remains in every canonical File B dollar total.
Distinct linked awards are not additive. The same award may receive obligations in multiple periods or program activities. Parent counts are set unions; child counts should never be summed.
